## 开发文档：同画幅片段自动缩放合成

### 背景
原片模式把低分辨率片段原尺寸居中，导致同宽高比片段合成后出现不必要的黑框。

### 目标
- [x] 自动按统一成片尺寸等比例 resize，同宽高比片段填满画面。
- [x] 比例不同时完整显示且只保留比例差必需的留边，不裁切、不拉伸。
- [x] 预览与正式导出布局一致，Windows 兼容编码保持。

- [x] 640×360 与 320×180 合成为 640×360，小片段四角没有补黑框。
- [x] 横屏、竖屏、方形同宽高比均自动填满统一画布。
- [x] 不同宽高比只保留必要留边，既有同尺寸无损像素一致测试继续通过。

### 风险点
- Resize 会改变像素采样，低分辨率放大不会产生真实新细节；无损编码指缩放之后编码无损。
- 当前真实片段 864×480 与 1056×608 的宽高比并非完全相同；自动适配后大黑框消失，但完整显示仍会有少量上下留边。
- 不覆盖已有成片，不修改日常项目，不调用云端。本次不重新打包 EXE。

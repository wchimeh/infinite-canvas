## 开发文档：双扇门独立动作

### 背景
用户反馈单手操作导致双扇门同时打开，扩写需要区分每扇门的接触和状态。

### 目标
- [x] 双扇门按独立物体描述，单手只操作所接触的门扇。
- [x] 保留参考图门型与用户明确的机械联动设定，不凭空添加联动机构。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/shot_nodes.py` | 修改 | 门扇状态与手部对应规则及缓存版本 |
| `services/backend/tests/test_shot_nodes.py` | 修改 | 扩写请求规则覆盖 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：输入现有分镜，要求仅在涉及双扇门时明确接触门扇、操作手、另一门扇状态及通过空间；双开须双手或有序操作；更新扩写版本。
- [x] 任务 2：验证规则进入 LLM 请求、旧扩写缓存失效，执行扩写与时长回归。
- [x] 任务 3：空闲时更新本地服务并验证健康状态，说明生成结果尚需画面验收。

### 验收标准
- [x] 规则覆盖手与门扇一一对应，未接触门扇保持原状态，联动只来自已有设定。
- [x] 测试通过，本地服务加载新规则。

### 风险点
提示词无法保证视频模型执行正确，不能把规则测试当作成片通过；不自动重跑付费任务，不修改已有用户素材。

### 验证记录
- 33 项扩写与时长测试通过，包含请求规则及缓存版本检查。
- 队列空闲时重启服务，健康接口返回 200，已打开本地页面。
- 未调用付费生成，实际门扇动作仍待成片复核。

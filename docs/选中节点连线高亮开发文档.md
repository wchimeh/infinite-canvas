## 开发文档：选中节点连线高亮

### 背景
选中节点时需要清楚看到它与前后节点的连接关系。

### 目标
- [x] 选中节点后，直接相连的输入线和输出线同时高亮。
- [x] 多选时高亮所有选中节点的关联线，取消选择后恢复。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/Canvas.tsx` | 修改 | 根据选中节点派生连线显示样式 |
| `apps/desktop/src/workbench.css` | 修改 | 关联连线高亮 |
| `scripts/node-edge-highlight-browser.mjs` | 新建 | 输入/输出、多选、取消和未关联线验收 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：派生连线显示属性；输入选中节点集合，输出关联连线 class，不修改实际连线选择或持久化数据。
- [x] 任务 2：添加清晰的深色加粗高亮；输入关联 class，输出与白色界面一致的高亮线。
- [x] 任务 3：构建与浏览器验收，检查单选、多选、取消选择及连线独立选择。

### 验收标准
- [x] 输入线和输出线同时高亮，未关联线不高亮。
- [x] 多选、取消选中、单独选线均正常。
- [x] 不改变连线选择、连接关系、撤销记录和项目数据。

### 风险点
- 高亮只表示直接连接，不递归点亮整条生成链。
- 仅视觉派生，不能把高亮线设为 selected，否则删除时会误删。

### 验证结果
- TypeScript 和前端构建通过。
- 浏览器验证输入/输出高亮、非关联线不变、多选、取消选择、独立选线及持久化隔离通过。

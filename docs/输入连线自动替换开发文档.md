## 开发文档：输入连线自动替换

### 背景
已连接上游的节点再次接入同一输入端口时，应直接替换旧连接。

### 目标
- [x] 文本、图片、视频、音频输入端口统一使用新连接替换旧连接。
- [x] 非法新连接保留原图，替换可撤销并更新下游待生成状态。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/store.ts` | 修改 | 同端口原子替换，先验证后修改 |
| `scripts/connection-replace-smoke.mjs` | 新建 | 模拟浏览器拖线、撤销与非法连接 |
| `scripts/smoke.mjs` | 修改 | 更新原来图片端口追加连接的旧断言 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：store.connect 输入新连接，移除候选图中同目标端口的数据/引用边，类型和循环检查通过后一次写入；其他端口及顺序边保留，目标和下游标记待生成，撤销快照包含整个替换操作。
- [x] 任务 2：浏览器验证文本/图片替换、不误删其他端口、撤销恢复和重做、类型错误及循环不删除旧线；业务请求模拟。
- [x] 任务 3：调整全链路 smoke 的图片连线数量及保存恢复断言，匹配替换语义。
- [x] 任务 4：类型检查、构建、新回归及画布相关回归通过。

### 验收标准
- [x] B 接入已有 A 的输入端口后只保留 B，其他输入不变。
- [x] 非法连接无副作用，替换操作撤销/重做正确。
- [x] 旧项目加载不迁移，用户重新连线时才替换该端口已有连线。

### 风险点
原先图片端口可以连接多路参考，本次按用户要求改为手动新连线替换同端口；多参考素材仍可通过节点的参考素材选择器配置。顺序边不参与依赖及替换。

- 节点点击定位、角色批量生成回归通过；语法检查通过。

- 所有执行的浏览器回归业务写入均模拟，未触发生成或修改用户项目。刷新工作台即可加载新前端。

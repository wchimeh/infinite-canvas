## 开发文档：任务中心手动展开

### 背景
提交生成任务时强制展开任务中心，打断画布操作。

### 目标
- [x] 任务提交和状态更新不改变面板展开状态及当前页签。
- [x] 以按钮短暂提示和运行中图标动画替代自动打开。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/App.tsx` | 修改 | 提交信号改为活动提示语义 |
| `apps/desktop/src/Timeline.tsx` | 修改 | 移除自动展开，增加活动提示，保留任务中心实例 |
| `apps/desktop/src/workbench.css` | 修改 | 提示与运行中动画、减少动态效果支持 |
| `scripts/task-panel-browser.mjs` | 新建 | 收起运行、动画和手动展开验收 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：重命名提交活动信号；输入任务提交成功，输出提示信号而非打开命令。
- [x] 任务 2：调整底部面板；输入提交/任务状态，输出提示动画，保持收起状态及选中页签；只响应用户点击展开。
- [x] 任务 3：添加动画样式；输入活动状态，输出短暂提示与持续旋转图标，减少动态偏好下静态显示。
- [x] 任务 4：添加并运行浏览器验收，验证收起后提交不展开、手动展开、运行完成动画结束和筛选保留；完成构建验证。

### 验收标准
- [x] 收起后提交、排队、完成均不自动打开面板。
- [x] 新任务提交有短暂提示，待处理任务有图标动画与数量。
- [x] 点击任务中心或展开按钮才打开，收起偏好刷新后保留。
- [x] 提交新任务不重置任务中心筛选，不自动切换时间线页签。

### 风险点
- 很快完成的本地任务仍需短暂提示，不能只依赖运行中状态。
- 动画尊重减少动态效果偏好；旧 EXE 不随源码修改自动更新。

### 验证结果
- TypeScript 与 Vite 构建通过。
- 隔离浏览器验证提交/排队/完成不展开、刷新保持收起、手动展开、筛选保留通过；减少动态效果时动画停用。

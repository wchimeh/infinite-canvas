## 开发文档：节点样式与时长输入优化

### 背景
视频节点时长控件的纵向排列和原生输入框与白色画布节点不协调。

### 目标
- [x] 时长标签、数字和单位横向对齐，节点与属性栏保持一致。
- [x] 统一节点标题、内容、端口与状态栏的间距和视觉层次。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/VideoDuration.tsx` | 修改 | 标签与单位结构 |
| `apps/desktop/src/style.css` | 修改 | 删除旧时长规则 |
| `apps/desktop/src/workbench.css` | 修改 | 白色主题节点与时长样式 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：VideoDuration 输入现有秒数，输出同样的修改回调；拆分标签、数值和单位，保持可访问名称及键盘操作。
- [x] 任务 2：style.css 删除旧时长规则，避免与主题规则冲突；验证只影响时长样式。
- [x] 任务 3：workbench.css 统一横向时长控件、节点留白、标题与端口间距；不遮挡连接点，保持白色主题。
- [x] 任务 4：执行构建和视频节点浏览器回归，截图检查时长、节点、属性栏；验证双向同步与保存不受影响。

### 验收标准
- [x] 时长横向显示，无拥挤或溢出，焦点清晰。

### 风险点
全局 label/input 样式可能覆盖局部规则，需要限定选择器；画布缩放会降低可读尺寸，检查正常缩放和缩小后的布局。

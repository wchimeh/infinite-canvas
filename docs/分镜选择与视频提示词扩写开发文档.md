## 开发文档：分镜选择与视频提示词扩写

### 背景
将提取的多个分镜选择为单条，再按照 ref-en.txt 扩写成适合视频生成的完整提示词。

### 目标
- [x] 分镜选择节点可选一条上游分镜，在本地输出该条内容和 4–15 秒时长。
- [x] 视频提示词扩写节点使用所选文本服务，严格遵循 ref-en.txt 的六段英文格式并保留原语言对白。
- [x] 所选分镜时长沿扩写节点传给视频节点，完整流程可保存和重跑。

### 设计
流程：提取分镜 → 分镜选择 → 视频提示词扩写 → 生成视频；参考素材仍直接连接视频生成节点。
分镜选择为本地节点，不收费；使用上游任务结果中的条目和内容指纹锁定选择，条目消失或内容变化要求重新选择，避免误选另一条。
扩写为文本队列节点，沿用文本服务、模型、预算和错误处理。按文件顺序输出 subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music；原样保留对白语言和参考编号，不臆造未提供的参考资产。
默认扩写节点支持文本和图片输入，纯文字也可运行。参考图片通过 image 端口或 referenceIds 传入，按连线后勾选顺序编号，以 image_url 数据 URI 发送给文本模型。文字可说明音视频角色但不直接上传音视频。

### 验收标准
- [x] 每个选择节点仅输出选中的一条分镜，未选或失效明确报错。
- [x] 4–15 秒时长经过扩写仍能传给视频生成。
- [x] 扩写请求包含完整 ref-en.txt 规范，输出六段顺序正确，不修改对白语言。
- [x] 两个节点队列、服务配置、费用和缓存行为正确。
- [x] 回归、构建与浏览器交互验证通过，新入口在本地服务可用。

### 风险点
仅模型遵守规范才能保证英文质量与参考关系准确；后端可校验结构，无法证明生成视频的参考保真度。参考编号必须与下游素材顺序一致。扩写需文本服务支持所选择的输入能力。新增节点不自动改接已有画布。

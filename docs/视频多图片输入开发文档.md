## 开发文档：视频多图片输入

### 背景
生成视频需要同时连接多张参考图片，同一个端口替换连线不能表达多个图片输入。

### 目标
- [x] 视频节点提供编号图片端口，默认两个，可增加至八个。
- [x] 按端口编号顺序传入工作流，保留单端口替换及素材多选。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/graph.py` | 修改 | 增加图片输入端口定义 |
| `services/backend/app/worker.py` | 修改 | 编号端口归并为有序 image 输入 |
| `apps/desktop/src/Canvas.tsx` | 修改 | 编号图片端口及添加输入按钮 |
| `apps/desktop/src/Inspector.tsx` | 修改 | 图片输入顺序说明 |
| `services/backend/tests/test_video_reference.py` | 修改 | 逆序连接与完整工作流多图回归 |
| `scripts/video-reference-smoke.mjs` | 修改 | 多端口展示、增加及多图勾选 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：graph 保留 image 为参考图 1，增加 image2 至 image8，类型均为 image，其他节点不变。
- [x] 任务 2：worker 将视频编号图片端口按编号排序，归一为 image 列表；预检按媒体类型识别，仍拒绝工作流未映射的输入。
- [x] 任务 3：Canvas 默认展示参考图 1/2，添加图片输入可扩展到 8，已有连线端口始终展示；动态刷新端口位置。
- [x] 任务 4：Inspector 说明连线图片按端口顺序、勾选图片随后按勾选顺序输入，数量以实际工作流为准。
- [x] 任务 5：后端逆序连线仍按编号输出、图片引用追加、两张图进入各自完整工作流字段的测试通过。
- [x] 任务 6：浏览器验证默认端口、扩展端口及两张图片同时选中；完整回归与构建、空闲重启。

### 验收标准
- [x] 多张图片可同时连接同一视频节点的不同图片端口。
- [x] 重连只替换对应端口，完整工作流按有序 image 索引读取。
- [x] 旧 image 连线兼容；视频、音频端口不受影响。

### 风险点
八个端口是编辑器上限，服务商工作流可能限制数量；未映射素材继续报错，避免静默丢图。空端口跳过，连线图片先于参考素材选择器中勾选的图片。

## 开发文档：扩写不传音频

### 背景
用户明确音频仅供视频生成参考，提示词扩写不发送参考音频。

### 目标
- [x] 扩写请求不包含独立音频或参考视频中的声音。
- [x] 视频生成独立接收音频，不要求扩写使用过同一录音。
- [x] 旧画布音频连接仍可打开，但扩写不执行这些依赖、不读取上传录音。

### 验收标准
- [x] 扩写 HTTP 请求无 input_audio，参考视频无音轨，qwen3.8-flash 不因旧音频而报错。
- [x] 扩写只连接音频或旧音频素材损坏时，不读取录音，也不执行音频生成上游。
- [x] 视频节点的普通参考音频与配套音轨映射正确，音频无需连接扩写。
- [x] 不自动修改用户项目接线、不切换模型、不调用收费生成。

### 风险点
- 扩写无法转录未输入的音频；需要准确台词时由文字明确提供。
- 旧音频端口保留兼容定义，已连接端口仅用于展示旧连线，不参与扩写。
- 生成模型的音色参考不保证逐字复现录音；本次不替换成片原音轨。

## 开发文档：角色三视图生成

### 背景
用户要求生成的角色图片为同一角色的三视图。

### 目标
- [x] 每个角色生成一张包含正面、侧面、背面的三视图。
- [x] 新建及已有角色图节点重新生成时都使用三视图要求。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_characters.py` | 修改 | 三视图提示、缓存、空输入及普通图片隔离回归 |
| `services/backend/app/worker.py` | 修改 | 合并角色输入后统一添加三视图约束 |
| `apps/desktop/src/App.tsx` | 修改 | 新角色节点提示词体现三视图 |
| `apps/desktop/src/Inspector.tsx` | 修改 | 展示角色三视图生成说明 |

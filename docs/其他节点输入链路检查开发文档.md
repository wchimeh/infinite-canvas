## 开发文档：其他节点输入链路检查

### 背景
检查其他节点是否也存在上游内容未使用、模型索要已有素材或输入被静默忽略的问题。

### 目标
- [x] 检查分镜、图片、参考图、视频、配音和音效的输入传递。
- [x] 拦截自定义工作流遗漏提示词映射及内置声音克隆忽略多段音频。
- [x] 验证本地素材与角色场景引用保持输入素材传递。

- [x] 任务 4：ComfyUI 在上传/提交前核对文本与媒体映射；遗漏输入报错，保留完整映射的正常流程。

### 验收标准
- [x] 文本及素材出现在实际适配器构造的请求中，不被静默遗漏。
- [x] 缺映射、多余音频与空输入在提交之前明确报错。
- [x] 分镜接受简短梗概；本地节点仍只输出输入内容。
- [x] 全量测试通过；图视频仅测试请求参数，不声称付费生成已验证。

### 风险点
- 之前依赖静默忽略提示词的工作流需要补充 prompt 映射或移除未使用的文本。
- 本地模型与云端工作流执行效果取决于实际配置，本轮不批量调用付费生成。

### 检查结果
| 节点 / 通道 | 结果 |
|---------|------|
| 提取分镜 | 上游原文进入 HTTP user 消息；指令补充简短梗概直接拆分要求，JSON 解析流程测试通过 |
| 分镜图、参考图创作 | 内置与完整云工作流中，合并文本和图片上传结果均进入最终请求 |
| 图生视频 | 内置与完整工作流中的文本及首帧输入传递通过；既有首尾帧校验测试通过 |
| 对白 / 配音 | 文本与参考声音传递通过；内置克隆收到多个参考音频明确拒绝 |
| 视频音效 | 文本及视频上传结果进入请求；不会仅提交描述而丢弃视频 |
| 自定义云工作流 | 有文本但缺 prompt 映射时拒绝，原有媒体完整映射检查保留 |
| 本地 ComfyUI | 缺 prompt 映射或未消费全部媒体时在上传 / 提交前报错 |
| 故事、素材、角色 / 场景引用 | 代码检查确认仍为本地原文或素材输出，不调用 LLM；既有回归通过 |

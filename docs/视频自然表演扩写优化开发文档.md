## 开发文档：视频自然表演扩写优化

### 背景
视频人物视线不明确、表演僵硬，需要将可执行的表演调度加入视频提示词扩写。

### 目标
- [x] 扩写明确站位、视线、对白节奏和听者反应，同时保留原剧情、台词及参考编号。
- [x] 旧扩写缓存不阻止新规则生效，不修改视频采样工作流。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/shot_nodes.py` | 修改 | 自然表演规则及版本号 |
| `services/backend/app/worker.py` | 修改 | 仅扩写节点缓存版本更新 |
| `services/backend/tests/test_shot_nodes.py` | 修改 | 请求规则和缓存版本验证 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：扩写指令接收既有故事、图片和时长，增加角色朝向、眼神目标、合理表演、三视图用途、时长预算和输出前自检；输出保持原六段结构。
- [x] 任务 2：仅 prompt.video_expand 的快照 adapterVersion 追加规则版本，使新运行不复用旧扩写缓存，其它文本节点版本不变。
- [x] 任务 3：验证真实请求构造包含规则、保留输入与图片顺序，并验证缓存版本隔离；执行后端回归。
- [x] 任务 4：确认队列空闲后重启本地服务，检查健康状态，完成使用说明。

### 验收标准
- [x] 规则覆盖视线、因果动作、倾听反应、镜头与人物运动区分、身份参考与姿态区分。
- [x] 用户刻意回避视线、独白、静止表演等要求优先；不擅自增删台词或虚构参考素材。
- [x] 新扩写使用新缓存版本，测试通过。

### 风险点
模型不一定完全遵循表演指令，规则与请求测试不能替代付费成片验收。过密台词且时长固定时无法保证自然语速，保留台词并优先压缩非必要动作，不承诺消除所有 AI 感。此次不自动提交生成，不改变现有成片。

### 验证结果
- 扩写节点测试 20 passed；后端完整回归 297 passed。
- 队列空闲后重启，健康接口返回 200。
- 未提交付费生成；需重新运行视频提示词扩写，再生成视频以评估自然度。

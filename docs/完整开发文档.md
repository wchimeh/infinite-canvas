## 开发文档：Windows 完整首版与本地模型扩展

### 背景
在已验收的 MVP 上补齐原始 Word 的 Windows 首版工程要求，以及此前列出的迁移、凭据、预算、并发、本地模型和时间线能力。

### 目标
- [x] 项目 ZIP 携素材可迁移、可校验；画布模板可复用且不携带凭据。
- [x] 界面可管理系统凭据、文本接口、本地 ComfyUI、模型价格和项目预算。
- [x] 调度支持按媒体类型限制并发，收费前原子预算预留，远端任务恢复不重复预留。
- [x] 时间线可裁切、定位、调节音量、区分对白/BGM、叠加视频，并预览真实合成结果。
- [x] 角色/场景设定、画布分组、候选对比、性能测试、CI 与发布验收齐备。
- [x] 分别记录真实云、本地模型、安装包、签名和独立机器的实际验收状态。

### 设计基线
沿用 React Flow/FastAPI/SQLite/FFmpeg/Tauri。用独立后端模块实现 ZIP、系统凭据、预算、本地模型和时间线领域逻辑，保持旧项目兼容。

迁移包由一致性 SQLite backup 加不可变媒体与 SHA-256 manifest 构成；导入始终创建新项目 ID 并重映射引用，不覆盖现有项目；拒绝路径穿越、链接、超限与缺失文件；剔除执行租约、云设置和凭据。模板仅保存节点定义、参数、位置及边，移除素材绑定和执行输出。

密钥通过 Windows Credential Manager 读写；环境变量为开发覆盖来源；公开配置存应用级文件，不入项目。接口只返回是否配置，不返回密钥。价格由用户按实际合同配置，金额用 Decimal，未知费用明确未知；有预算上限时未知价格阻止云提交。按 task_id 在 SQLite 事务内预留/释放费用，提交不确定保留预留，不能当作已结算账单。

ComfyUI 接入用户已经安装的本地服务，不下载任意模型。健康检查、object_info 校验、版本化 API workflow 模板与字段映射、输入上传、prompt/history 查询、输出获取作为独立适配器；默认仅允许 loopback 服务。安装/GPU诊断提供实际检测信息；缺模型时明确阻止提交。

时间线兼容现有顺序 V1。支持显式 startMs、V2 叠加、源 inMs、gain、muted、fadeInMs/fadeOutMs 和位置/尺寸；音频分 A1/A2。预览使用真实 FFmpeg 合成低分辨率 MP4，禁止把源镜头预览称为混音预览。保留批准门槛和导出 manifest。

原始文档明确非首版的协作/云账户、模型市场、全功能 NLE（多机位、光流、关键帧曲线）与 macOS 不纳入 Windows 首版验收。签名、真实云计费、模型运行与干净机器验证需要实际外部条件，不能通过 Mock 替代。

### 风险点
- 当前无真实云端凭据/文本服务配置，不能自行编造；真实生成可能计费，需可用账号和明确测试额度。
- 本地 ComfyUI/GPU 模型运行时及签名证书不随项目附带，适配完成不能等同于真实模型或正式签名通过。
- 价格配置来自用户合同而非虚构服务商价格；估算及预留不代表云端实际结算。
- 多轨合成提高 CPU/磁盘消耗；预览缓存需按输入快照失效。
- CI 配置可本机校验，远程 CI 是否通过以真实运行记录为准。

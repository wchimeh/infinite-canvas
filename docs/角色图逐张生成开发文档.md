## 开发文档：角色图逐张生成

### 背景
用户要求角色图一张一张生成，不能因媒体并发数较高而同时提交多张角色图。

### 目标
- [x] 所有项目的角色图生成任务同时最多占用一个名额。
- [x] 云端排队与运行都占用角色名额，完成后自动调度下一张。

### 风险点
- 限制属于任务级串行；自定义工作流本身的批量输出数量由工作流控制。
- 云端不支持取消时，取消后的远端计算可能继续，沿用现有取消提示。

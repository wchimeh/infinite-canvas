## 开发文档：视频裁剪节点

### 背景
按用户指定开始和结束时间截取视频，输出可试听预览并连接下游的新视频素材。

### 目标
- [x] 新增视频输入/输出的本地视频裁剪节点。
- [x] 支持小数秒、保留音轨、配置持久化、缓存及重新裁剪。

### 任务清单（必须全部标记完成）
- [x] 任务 1：实现视频处理器；输入单个视频和 trimStart/trimEnd 秒数，输出 H.264/AAC MP4，保留首条可选音轨，拒绝无视频和无效时间。
- [x] 任务 2：注册 video.trim；输入视频端口，输出视频端口，可从列表添加。
- [x] 任务 3：报价加入本地视频裁剪；输入快照，输出零费用。
- [x] 任务 4：队列加入视频裁剪；输入快照，输出 local。
- [x] 任务 5：调度器接入视频裁剪；输入上游视频和配置，输出视频素材，支持缓存及重新运行。
- [x] 任务 6：界面复用裁剪区间，显示视频说明及裁剪按钮；输入时间，输出持久化配置，隐藏云端、风格、提示词和参考素材选择。
- [x] 任务 7：任务中心分类加入视频裁剪；输入任务，输出本地标识。
- [x] 任务 8：新增并运行后端测试；验证小数区间、音轨保留、静音视频、越界、原素材保留和本地缓存。
- [x] 任务 9：新增浏览器验证并执行；验证参数保存、实际运行、视频预览和前端构建，运行相关回归。

### 验收标准
- [x] 输出时长符合指定区间（容许一帧或编码音频误差），结束留空到末尾。
- [x] 原素材不变、有音轨则保留，无音轨也能成功。
- [x] 全部在本地运行，配置保存重开有效，可接下游视频输入。
- [x] 非法时间/越界/缺失输入明确报错，不调用云端服务。

### 风险点
- 精确裁剪需要重新编码，耗时与分辨率、片段时长有关；输出 H.264/AAC MP4。
- 输出第一条视频和可选第一条音轨，不导出额外音轨、字幕轨。
- 本次不自动重新打包 EXE。

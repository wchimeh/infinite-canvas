## 开发文档：工作台界面与可用性优化

### 背景
现有工作台字体偏小、任务操作拥挤，生成文本仍显示空占位；用户明确要求改为白色系，统一优化可读性和布局。

### 目标
- [x] 提高画布、属性和任务信息可读性，统一控件层级及键盘焦点。
- [x] 文本生成成功直接显示结果预览，任务中心减少无关操作。
- [x] 验证桌面和窄屏布局及完整功能回归。

| 文件路径 | 操作类型 | 说明 |

| `apps/desktop/src/Timeline.tsx` | 修改 | 任务页隐藏时间线专用工具 |

### 风险点
- 字号加大可能影响节点和面板密度，需通过截图及多尺寸测试调整。
- 使用系统中文字体，保持离线可用，不引入远程字体。
- 本轮不调用付费生成，不重打包桌面安装程序。

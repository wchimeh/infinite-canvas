## 开发文档：生成费用提示开关

### 背景
用户希望可以在设置中关闭每次生成前的费用确认弹窗。

### 目标
- [x] 设置中可关闭费用确认，保存后立即生效且重启保留，默认开启。
- [x] 关闭仅跳过确认弹窗，继续执行配置检查、费用估算及已有预算限制。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/credentials.py` | 修改 | 应用级布尔设置 |
| `apps/desktop/src/types.ts` | 修改 | 设置类型 |
| `apps/desktop/src/Settings.tsx` | 修改 | 费用与并发页开关及保存 |
| `apps/desktop/src/App.tsx` | 修改 | 提交前读取最新开关 |
| `scripts/cost-confirmation-browser.mjs` | 新建 | 隔离浏览器验证 |

- [x] 默认与旧版行为一致；用户可自主关闭或重新开启。

### 风险点
关闭提示后生成可能直接产生服务商费用，开关旁说明；不改变云端总开关或预算上限，不操作日常设置，不触发付费生成。

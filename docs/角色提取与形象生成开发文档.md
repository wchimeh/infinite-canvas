## 开发文档：角色提取与形象生成

### 背景
用户需要从剧本提取人物并生成角色形象，当前只有绑定已有图片的角色参考节点。

### 目标
- [x] 提取角色节点调用所选 LLM，返回可审核的人物设定。
- [x] 确认角色后加入角色库并创建逐角色形象节点。
- [x] 角色形象节点使用真实图片工作流，采用图片后绑定角色参考版本。

### 任务清单（必须全部标记完成）
- [x] 任务 1：graph 定义 character.extract（文本→文本）和 image.character（文本/参考图→图片），节点列表自动展示。
- [x] 任务 2：generation_profiles 将角色提取归入文本服务，角色图归入内置及自定义图片工作流。
- [x] 任务 3：providers 对故事/剧本提取角色 JSON；输出 name、description、appearance、wardrobe、restrictions；校验非空姓名及字段类型，限制角色数和字段长度，丢弃未知字段，兼容代码围栏，更新版本。

### 验收标准
- [x] 左侧能添加两种节点，角色提取可选不同文本服务和模型。
- [x] 角色草案经确认入库、每人一张形象节点，同次确认不重复。
- [x] 角色图可选工作流，沿用媒体并发，图片采用后可用于角色参考及分镜。
- [x] 测试通过；模拟验收不调用付费图视频生成。

### 风险点
- LLM 角色输出需要人工审核；提取不会自动改写已有角色。
- 旧自定义图片工作流需在适用节点中加入角色图；内置 Image2 直接支持。
- 独立添加的角色图节点可连到下游；只有从角色确认创建的节点会在采用时回写对应角色库。

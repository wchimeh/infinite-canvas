## 开发文档：AI 短剧无限画布

后续完整开发正在按 [完整开发文档](完整开发文档.md) 推进。本文下列勾选和 T21 结果仅代表首轮 MVP，不能解释为所有产品工作已经完成。

### 背景
依据《无限画布开发文档.docx》建立本地优先的短剧创作工具，通过 generate_tool 已定义的 RunningHub 工作流调用云端 AI。

### 目标
- [x] 建立可启动、可保存重开的 React Flow + FastAPI + SQLite 创作工作台。
- [x] 支持真实 RunningHub 图片/视频/音频生成、持久任务、取消、重试与缓存。
- [x] 支持素材版本、角色/场景、分镜、时间线及 FFmpeg 导出。
- [x] 提供 Windows 桌面壳配置、启动文档和可重复运行的验收测试。

### 设计基线
沿用用户提供文档的架构，不重新选型。开发期使用 Web + 本地 API，Tauri 2 作为桌面壳。服务仅监听 loopback，通过本次启动随机 token 验证；UI/API 同源发布。SQLite 使用 WAL、事务队列及租约。源素材内容寻址，生成输出不可变；项目保存有版本乐观锁。执行快照包含节点参数、Provider 版本和输入资产 hash，顺序关系独立于 DAG。

云端适配复用 generate_tool 的工作流构造函数，通过显式请求构造入口提取参数；不在服务器调用原有长时间阻塞生成函数。提交后立即持久化 external_task_id；提交响应不确定时标记待确认，不自动重新提交收费任务。默认离线，用户在界面启用云生成。密钥改用环境变量，不写项目数据库。文生图/1–8 参考图、LTX/Wan 视频、TTS/授权参考音色、音效来自已有脚本。文本扩写/分镜使用可配置兼容 Chat Completions 的独立文本接口；未配置时允许手动编辑，显示未就绪。

视觉：专业剪辑工作台，蓝灰背景 #111923、面板 #192431、分隔 #2b3b4b、文本 #e7edf4、辅文 #9eafbf、强调 #78b7df；中文字用系统雅黑，时间码用 Consolas。画布节点以真实媒体预览为中心，状态同时有文字。避免虚构已生成素材与进度百分比。

### 风险点
- 当前仅有需求文档和脚本，没有现成应用；原文包含 8–12 周完整产品路线。首轮重点是可运行的 MVP，超出已实现范围的性能指标、安装包签名、本地 ComfyUI、复杂剪辑需要明确披露。
- Rust 工具链位于 .runtime/cargo 和 .runtime/rustup，未加入系统 PATH；桌面构建需在当前进程设置 CARGO_HOME/RUSTUP_HOME 并扩展 PATH。FFmpeg 已通过本机 .env 的 FFMPEG_DIR 配置并验证真实导出。
- 原脚本含明文密钥；迁移为环境变量，不在日志或文档重述密钥。
- 云工作流和参考模型权限需真实账号验证；自动验收不发起收费生成。
- Provider 不提供取消/成本/进度时仅展示真实能力，不伪造。
- 云提交请求发生网络中断后不能判断是否已收费：转待确认错误，由用户核查后显式重试。

## 开发文档：参考图勾选连线同步

### 背景
节点属性中勾选的图片参考需要同时显示为画布连接线。

### 目标
- [x] 勾选图片自动创建或复用素材节点并连线，取消勾选移除连接。
- [x] 连线是唯一图片输入来源，避免勾选与连线重复传图。

### 验收标准
- [x] 每张勾选图片都有对应连线，自动出现下一个端口；重复勾选不重复创建。
- [x] 取消勾选移除对应线，素材和素材节点保留；删线后勾选状态同步取消。
- [x] 原有勾选图片首次编辑时迁移为连线，不重复传图；音视频保持原逻辑。
- [x] 多图顺序稳定，超限不部分修改；一次撤销恢复；保存重开一致。

### 风险点
- 生图最多 8 张、视频及视频提示词扩写最多 9 张，实际工作流仍可能有更小限制。
- 复用生成节点已有图片输出时只删除对应图片输入边，不修改生成节点本身。
- 需更新后端端口契约并重启服务；旧 EXE 暂不更新。

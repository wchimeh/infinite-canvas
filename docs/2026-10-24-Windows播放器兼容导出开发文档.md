## 开发文档：Windows 播放器兼容导出

### 背景
无损 H.264 使用 High 4:4:4 Predictive，用户的 Windows 默认播放器出现白屏，需要常规 H.264 兼容导出。

### 目标
- [x] 默认输出 Windows 兼容高画质 MP4，保留原分辨率及原片模式帧率。
- [x] 保留显式无损选项，明确兼容版属于高质量有损编码。
- [x] 为已诊断的成片生成独立兼容副本，保留原文件。

- [x] 默认正式成片采用标准 H.264 High、8-bit yuv420p、AAC，不再使用无损 High 4:4:4 Predictive。
- [x] 分辨率与帧率不因选择兼容编码改变；显式无损仍逐像素一致。
- [x] 页面明确两种编码的区别及兼容限制。

### 风险点
- 兼容模式有轻微压缩损失，不能宣称数学无损；保留原无损版本。
- 极高分辨率、帧率仍可能超过具体机器的解码能力；本次实际成片为 1056×608、24 fps。
- 本次不自动重新打包 EXE，不提交代码，不调用云端。

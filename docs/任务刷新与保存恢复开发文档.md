### 验收标准
- [x] 较早但未完成的任务不被最近 200 条挤掉，无重复条目。
- [x] 同一轮持续断网不会让提示永久显示；恢复时提示一次。
- [x] 未保存编辑在失败后保持，恢复或手动重试成功后清除错误。
- [x] 自动重试不用于生成提交，冲突不强行覆盖。

### 风险点

- 不修改用户日常项目，不自动打包或提交代码。

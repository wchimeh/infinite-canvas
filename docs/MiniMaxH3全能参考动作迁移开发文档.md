## 开发文档：MiniMax H3 全能参考动作迁移工作流

### 背景
将生成视频默认工作流替换为用户提供的完整 JSON，按实际四类参考输入裁剪 136 节点。

### 目标
- [x] 默认调用新完整工作流，提示词 144、时长 132、种子 129、结果 92。
- [x] 支持 9 图片、3 视频画面、3 音频、3 视频音频独立输入，并自动显示下一个连接点。
- [x] 删除未使用的 136 参考输入和无用加载器，保留正确分支及用户参数。

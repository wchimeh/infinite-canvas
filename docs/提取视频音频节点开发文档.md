## 开发文档：提取视频音频节点

### 背景
需要从导入或生成的视频中提取原始声音，供音频参考、试听和时间线使用。

### 目标
- [x] 增加视频输入、音频输出的本地节点，不依赖大模型或云端工作流。
- [x] 使用FFmpeg提取第一条音轨为WAV，保留原始视频；明确提示无音轨或输入错误。
- [x] 可缓存复用、重新提取、预览和连接下游，归本地队列且费用为零。

### 风险点
依赖本地FFmpeg/ffprobe；默认只提取第一条音轨，WAV比压缩音频大。不做声音分离或配音生成。已有工作区改动全部保留，不重启日常服务、不调用付费接口、不自动提交推送。

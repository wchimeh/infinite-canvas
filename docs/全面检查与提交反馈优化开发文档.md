### 验收标准
- [x] 快速重复点击不会在同一提交期间产生多个运行请求。
- [x] GET 详情失败不提示重新生成，自动轮询仍可恢复任务列表。

### 风险点
- 浏览器提交锁不替代数据库对活跃任务的保护。
- 跨项目切换期间旧请求不能覆盖新项目的任务或节点状态。
- 本轮真实图片视频仍不付费试跑；使用模拟响应验证异常路径。

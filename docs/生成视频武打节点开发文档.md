## 开发文档：生成视频-武打

### 背景
新增独立视频节点调用用户提供的H3文武05工作流，支持动态参考素材和常用参数配置。

### 目标
- [x] 新增“生成视频-武打”，默认使用指定文武05工作流。
- [x] 支持1–9张图片，以及可选的1–3段音频、1–3段视频；按实际数量移除示例加载器。
- [x] 配置时长、比例、MP、步数、CFG、种子及武打/动作修复/连贯动作/速度强度。
- [x] 保留原模型、LoRA、SelfLift采样及输出链路，独立于已有生成视频节点。

### 验收标准
- [x] 原有视频节点行为不变，新节点可以独立添加与运行。
- [x] 图片映射ref_images、音频映射ref_audios、视频映射ref_videos，不留下模板示例素材。
- [x] 参数准确覆盖工作流，固定种子可复用，随机种子按重新提交变化。
- [x] 默认10步、0.5MP、CFG1，模型与各LoRA沿用指定模板。
- [x] 未调用收费云端生成，明确云端自定义节点/模型依赖尚需真实环境验证。

### 风险点
- 此工作流依赖SelfLiftH3Sampler、BlockSparseAttention等自定义节点及多个模型，云端必须安装对应资源；本地验证不能证明远端资源可用。
- 本节点必须至少一张图片，音频和视频可不接；不会自动补示例素材。
- 沿用模板的24fps输出及帧数对齐规则，不以对白时长估算拦截提交。
- 采用静态导入的Python模板随后端打包，不依赖开发目录中的中文JSON路径。

## 开发文档：默认视频工作流自动匹配

### 背景
将用户提供的 workflow_json_new.py 工作流接为生成视频默认值，并按实际参考数量自动匹配模板。

### 目标
- [x] 默认 MiniMax H3 工作流从文件的 27 份模板中自动匹配实际图片和音频/视频数量。
- [x] 使用完整图调用 rh_api_generate_by_workflow，覆盖提示词、素材、时长及随机种子。

### 任务清单（必须全部标记完成）
- [x] 任务 1：读取用户文件中现有字典模板，按图片 1–9、可选单音频或单视频选择；生成 prompt/seconds/seed/media 映射，输出节点 271，清理未引用素材加载节点，不改原始模板。
- [x] 任务 2：目录加入 builtin-minimax-h3，未指定视频工作流时自动解析到此配置；构建完整工作流请求，仍禁止 LTX/Wan 默认。

- [x] 任务 4：覆盖 27 个组合、无图及超额/混合输入拒绝、时长提示词替换、模板不变、上传和 rh_api_generate_by_workflow 调用测试；更新原默认禁用测试。

### 验收标准
- [x] 未指定工作流的视频节点自动使用 MiniMax H3，并按运行时实际素材数量选模板。
- [x] 每张图片/音频/视频映射到正确加载节点，输出从节点 271 获取。
- [x] 不残留示例提示词、示例文件或未使用加载节点，不静默丢弃输入。

### 风险点
源文件只有 1–9 图、1–9 图+1 音频、1–9 图+1 视频三组模板；不支持无图、多音频、多视频或音视频同时输入。视频模板将 VHS_LoadVideo 的输出 2 接入 ref_audios，使用视频音轨，不是画面参考。编辑器 9/3/3 能力仍保留给其它完整工作流。模板能力边界明确提示，不擅自扩造未知模型输入。

## 开发文档：素材重命名

### 背景
素材库需要人工调整素材名称，便于查找和引用。

### 目标
- [x] 图片、视频和音频支持重命名并立即持久化。
- [x] 保留素材 ID、文件路径和内容，已有引用不失效。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/store.py` | 修改 | 原子更新素材名称 |
| `services/backend/app/main.py` | 修改 | PATCH 素材接口 |
| `apps/desktop/src/AssetRename.tsx` | 新建 | 编辑、保存、取消与错误展示 |
| `apps/desktop/src/App.tsx` | 修改 | 素材重命名入口与当前项目状态更新 |
| `apps/desktop/src/workbench.css` | 修改 | 素材栏编辑表单布局 |
| `services/backend/tests/test_asset_rename.py` | 新建 | 名称校验、持久化及引用保持 |
| `scripts/asset-rename-browser.mjs` | 新建 | 真实界面改名及刷新验收 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：存储层重命名；输入素材 ID、名称，输出更新后的素材；名称去首尾空白且限 1–200 字符，拒绝控制字符和文件名非法字符。
- [x] 任务 2：添加 PATCH 接口；输入名称请求体，输出素材元数据，保留原会话校验。
- [x] 任务 3：新增编辑组件；输入当前名称与保存回调，支持回车保存、Esc/按钮取消、错误保留编辑内容。
- [x] 任务 4：接入素材库；输入改名结果，更新素材列表及已打开的预览，项目切换后不写入旧响应。
- [x] 任务 5：调整表单样式，窄素材栏内可操作。
- [x] 任务 6：测试名称校验、持久化和 ID/文件/引用不变，验收界面和构建。

### 验收标准
- [x] 三类素材可改名，保存后刷新依然显示新名称。
- [x] 取消不修改名称，空名称不可保存，失败可重新编辑。
- [x] 原文件及引用不变，不触发重新生成；节点/时间线自定义标题独立保留。
- [x] 类型检查、构建、后端与浏览器验收通过。

### 风险点
- 修改的是素材显示名称，不修改文件格式和磁盘存储路径。
- 使用项目操作快照防止异步返回污染其他项目；数据库事务防止并发删除后复活素材。
- 旧 EXE 和已运行后端需要更新后才能使用接口。

### 验证结果
- 10 项后端回归通过，TypeScript 与 Vite 构建通过。
- 浏览器验证取消、空名称、非法字符提示、回车保存、刷新持久化及素材引用通过，截图复核完成。
- 未重启日常服务，未重新打包 EXE。

### 背景

### 目标
- [x] 新建工作流默认使用完整 JSON 模式。
- [x] 切换提交模式后可以恢复当前工作流的 JSON 草稿。
- [x] 单独检查当前工作流，并显示检查结果。

### 任务清单（必须全部标记完成）

### 验收标准
- [x] 新建完整工作流且切换两次不会丢失 JSON。
- [x] 检查失败显示具体原因，成功不改变已保存配置。
- [x] 旧 ID 工作流仍可使用，完整图原有生成接口保持正常。

### 风险点
- 模式切换备份仅在当前云端工作流页面有效；切换设置页签、关闭或恢复已保存设置后丢弃备份。
- 本地检查只验证配置结构，不验证云端模型可用性，不产生云端费用。

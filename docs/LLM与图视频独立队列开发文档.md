## 开发文档：LLM 与图视频独立队列

### 背景
用户要求 LLM 独立调度，图片和视频共用队列且总并发可配置。

### 目标
- [x] LLM 与图视频使用独立执行池及容量。
- [x] 图片和视频共同占用可配置的 1–8 个并发名额。
- [x] 保留依赖、远端轮询、取消及恢复行为。

### 任务清单（必须全部标记完成）

- [x] 任务 2：数据库领取按队列过滤并合计图视频占用；输入队列及容量，输出原子领取的任务；远端排队也计入占用。
- [x] 任务 3：执行器按 text/media/audio/local 分池；输入待运行任务，输出互不占用执行线程的调度，依赖仍需完成。

- [x] 任务 5：设置页显示“图片＋视频”和“LLM 文本”额度；输入用户并发值，输出可保存的共享容量。

### 验收标准
- [x] media=2 时，图片与视频运行和远端排队合计不超过 2；LLM 仍可领取。
- [x] LLM 耗时请求不占图视频线程，图视频请求也不占 LLM 线程。
- [x] 设置可独立配置图视频总并发和 LLM 并发。

### 风险点
- 旧 image/video 字段仅兼容读取，新 media 配置优先；旧配置迁移为两类并发之和（上限 8）。
- 本地输入处理及音频保留独立执行池；降低额度不强制终止已提交的云端任务。
- 队列隔离不绕过依赖：依赖文本结果的图片仍须等待文本完成。

## 开发文档：取消视频生成对白时长校验

### 背景
用户要求视频生成不因对白估算时长超出分配时长而阻止提交。

### 目标
- [x] 视频生成直接使用原提示词和所选时长，不做对白语速及分段时间预算校验。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_timing_budget.py` | 修改 | 长对白仍可提交，原参数保持不变 |
| `services/backend/app/worker.py` | 修改 | 移除视频生成阶段的时间预算校验 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：修改回归测试；输入超长对白及分段时间不足的提示词，输出提交服务商且提示词、时长不变的断言。
- [x] 任务 2：移除视频阶段校验；输入视频生成任务，输出可提交的原始参数。
- [x] 任务 3：执行相关回归；输入最终代码，输出测试通过记录。

### 验收标准
- [x] 视频节点不再报告“对白估算至少需要…秒，但仅分配…秒”。
- [x] 不自动精简台词、不改写时长、不发起真实收费生成。

### 风险点
模型能否在所选时长内完整说出台词由模型决定。本次仅取消视频生成节点的拦截，扩写节点的既有规则不在本次修改范围。

### 验证记录
- 72项相关回归测试通过。测试验证长对白和分段时间不足仍提交模拟服务商，提示词和seconds保持原值，未调用真实云端。

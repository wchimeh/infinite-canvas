## 开发文档：移除默认视频模型

### 背景
视频使用用户配置的全能参考工作流，不再提供默认 LTX/Wan 生成入口。

### 目标
- [x] 视频工作流目录不显示内置 LTX/Wan，也不自动回退到这些模型。
- [x] 未选择视频工作流时显示配置提示，已有项目和运行结果保留。

| `apps/desktop/src/Inspector.tsx` | 修改 | 去掉模型选择与默认工作流文案，缺配置禁止运行 |

## 开发文档：统一视频与音频素材节点

### 背景
视频采用全能参考工作流，仅需一个生成视频入口，音频只需素材节点。

### 目标
- [x] 新建入口只保留一个生成视频节点及音频素材节点，隐藏视频音效和对白配音入口。
- [x] 生成视频可连接和选择图片、视频、音频参考，按工作流映射提交。

- [x] 新节点列表显示生成视频、音频素材，不显示视频音效和对白配音。
- [x] 图片/视频/音频连线与参考素材都能到达完整工作流映射。
- [x] 全能参考工作流不被无条件首帧检查阻止，仍走 rh_api_generate_by_workflow。

### 风险点
全能参考必须使用实际服务商工作流及正确的输入映射，不能用内置 LTX/Wan 工作流代替。没有擅自更改用户已选工作流。历史音效和配音节点仍保留后端兼容，新增入口隐藏。

### 风险点
- 完整图必须为 API 格式，不支持直接执行带 widgets_values 的编辑器格式。
- 云端模型和自定义节点可用性需由用户在实际服务中确认；本次使用模拟请求验证，不产生云端费用。
- workflowId 的默认占位值沿用用户提供脚本；已配置时使用用户指定值。

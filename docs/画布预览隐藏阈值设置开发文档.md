## 开发文档：画布预览隐藏阈值设置

### 背景
低配置优化固定在缩放低于50%时隐藏预览，用户需要自行调整阈值或关闭。

### 目标
- [x] 设置中可开启/关闭缩小时隐藏预览，并调整10%–100%的整数阈值。
- [x] 默认开启、阈值50%，保存后即时生效，重启与切换项目后保持。
- [x] 缩放只在跨越阈值时切换概览，保留现有性能优化。

### 验收标准
- [x] 默认50%，可改为例如30%或80%，错误数值不能保存。
- [x] 关闭时在小比例下也显示内容，重新开启沿用上次阈值。
- [x] 保存立即生效；关闭设置不保存则不改变画布；刷新保留设置。
- [x] 节点尺寸、连线和拖动不受影响。

### 风险点
- 关闭隐藏会增加大画布的绘制负担，在设置中简短说明。
- 使用应用设置保存而非浏览器临时状态，避免本地服务端口变化导致偏好丢失。

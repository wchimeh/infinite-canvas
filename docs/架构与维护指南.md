# 架构与维护指南

## 目录与职责

| 目录或文件 | 职责 |
|---|---|
| `apps/desktop/src/App.tsx` | 项目加载、保存、运行前估价与提交、面板协调 |
| `apps/desktop/src/store.ts` | 画布节点/连线状态、撤销重做、节点布局与配置修改 |
| `Canvas.tsx` / `Inspector.tsx` | 节点卡片、动态连接点、属性及候选结果操作 |
| `Settings.tsx` / `GenerationProfiles.tsx` | 服务凭据、文本模型、云端工作流与并发设置 |
| `TaskCenter.tsx` / `QueueSummary.tsx` | 任务状态、结果与队列概览 |
| `Timeline.tsx` | 已审核素材的时间线编辑 |
| `style.css` / `workbench.css` | 基础布局及白色主题覆盖；新增主题规则优先集中到 workbench.css |
| `apps/desktop/src-tauri` | Windows 桌面壳与后端 sidecar 启动 |
| `services/backend/app/main.py` | FastAPI 路由、会话校验和服务生命周期 |
| `graph.py` | 节点定义、端口类型、图校验和拓扑排序 |
| `store.py` | 每项目 SQLite、不可变素材、任务状态、租约与缓存 |
| `worker.py` | 快照冻结、上游依赖、输入收集、分队列调度与生成状态机 |
| `providers.py` / `comfy.py` | RunningHub、兼容 Chat Completions 文本服务、ComfyUI 适配 |
| `generation_profiles.py` | 服务选择、工作流校验与字段映射 |
| `video_workflow.py` | 根据参考数量选择 MiniMax H3 完整模板 |
| `shot_nodes.py` | 分镜选择、视频提示词扩写规范、自然表演规则版本 |
| `credentials.py` / `costs.py` | 服务设置、凭据及费用估算/预算账本 |
| `timeline.py` / `exporter.py` | 时间线校验、FFmpeg 预览和导出 |
| `generate_tool` | 云端脚本和工作流模板；不承担本地模型推理 |
| `scripts` | 启动、语法检查、浏览器验收、桌面打包与发布清单 |
| `services/backend/tests` | 后端单元、契约和集成测试 |
| `docs` | 开发任务、验收记录及维护说明 |

上述省略目录的前端文件位于 `apps/desktop/src`，后端文件位于 `services/backend/app`。

## 生成调用链

1. 前端保存画布，通过 `/runs/estimate` 估价，然后向 `/runs` 提交选中节点。
2. Worker 校验图及服务配置，冻结节点配置、上游依赖和工作流选择。
3. 调度器按 LLM、图片＋视频、音频、本地处理队列领取任务，等待依赖完成。
4. 收集上游输出与锁定素材，构建输入哈希；命中缓存则复用，否则进入服务调用。
5. 文本请求交给所选服务；完整云端工作流先上传素材，再替换副本中的字段，调用 `rh_api_generate_by_workflow`。
6. 云端提交返回任务 ID，后续轮询该任务并下载结果；不会每次轮询重新生成。
7. 素材与任务结果落盘，前端刷新结果供用户审核、采用和加入时间线。

运行成功只表示生成完成，不表示用户已采用。不要把排队、已提交云端、缓存复用与本地输入处理混为一种状态。

## 缓存与版本

- 缓存键包含内容输入、上游输出、适配器版本和生成配置。
- `overwriteCache` 是调度选项，从内容哈希中排除；开启后跳过旧缓存，成功结果供后续相同输入复用。
- 覆盖只针对本次请求的节点；作为依赖的上游可以复用。历史素材不删除。
- 视频扩写规则变化时更新 `EXPANSION_VERSION`，使旧扩写缓存失效；不要为了单个节点的规则变化使全部文本缓存失效。
- 内置完整工作流的行为变化应同步评估其 profile `version`。旧任务的配置快照不应被用户后续修改覆盖。

## 视频与参考素材边界

编辑器允许 9 张图片、3 段音频、3 段视频。内置 `workflow_json_new.py` 只有 27 种组合：1–9 图，以及分别加 1 音频或 1 视频的变体；视频变体读取视频音轨。不要通过丢弃素材伪装成支持其它组合。

参考图片顺序必须在“视频提示词扩写”和“生成视频”两处一致。文本扩写只输出文本，不会把图片传递给下游；视频仍需接入相应素材。

## 开发与验证

按根目录 README 安装锁定依赖。常用命令：

```powershell
pnpm lint
pnpm build
pnpm test
```

媒体测试需要 FFmpeg/FFprobe。`pnpm verify` 汇总上述检查。后端测试默认使用临时数据和模拟服务，不应依赖开发者本机密钥。

浏览器检查须先启动服务并安装 Playwright Chromium。`scripts/video-reference-smoke.mjs` 对业务写入使用拦截模拟；`scripts/smoke.mjs` 包含真实本地写入，必须在独立测试数据目录下使用，不要对日常创作项目运行。

新增节点时依次检查：后端定义与校验 → 前端类型和属性 → 快照与输入收集 → 服务映射 → 缓存/队列 → 测试。用户要求代码变更前先写任务文档，按最小任务执行并及时勾选。

## 本地文件与发布

`.env`、`data/`、`.runtime/`、依赖、构建缓存和 Office 锁文件不提交。`.env.example` 只提供空配置项。工作流中的公开模型名和节点 ID 属于模板配置，不是账户凭据。

仓库保留远端 Apache-2.0 许可证；第三方模型、服务和模板的使用仍受各自条款约束。Windows 安装包由现有 GitHub Actions 工作流构建，源码测试通过不等于安装包签名或真实付费生成已验收。

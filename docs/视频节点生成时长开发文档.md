## 开发文档：视频节点生成时长

### 背景
视频时长仅在右侧属性栏可编辑，用户需要在画布视频节点上直接输入。

### 目标
- [x] 视频节点直接编辑生成时长，与右侧属性同步并保存。
- [x] 默认 5 秒，输入范围 1–30 秒，沿用 seconds 工作流映射。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/VideoDuration.tsx` | 新建 | 共用时长编辑控件 |
| `apps/desktop/src/Canvas.tsx` | 修改 | 节点时长入口 |
| `apps/desktop/src/Inspector.tsx` | 修改 | 复用输入控件 |
| `apps/desktop/src/style.css` | 修改 | 节点控件布局 |
| `scripts/video-reference-smoke.mjs` | 修改 | 同步与保存检查 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：共用时长控件接收 seconds 和修改回调；输入失焦或回车提交 1–30 秒数值，空值恢复原值，可正常清空后重输。
- [x] 任务 2：Canvas 视频卡片接入控件；修改写入节点 config.seconds，不触发拖拽。
- [x] 任务 3：Inspector 复用控件；同一配置同步到两处。
- [x] 任务 4：style.css 增加紧凑的节点时长布局，保持白色主题。
- [x] 任务 5：浏览器验证默认值、双向同步、清空重输、范围限制和保存后重载；执行构建及既有后端时长映射测试。

### 验收标准
- [x] 画布节点可直接输入秒数，右侧同步，保存重载后保留。
- [x] 输入空白不意外写入 0；范围限制生效；完整工作流时长映射测试通过。

### 风险点
云端输出会根据工作流帧数规则取整，实际时长可能略有偏差；自定义工作流需要映射 seconds。输入提交使用失焦或回车，运行按钮点击前会先失焦提交。此次不自动重新生成已有视频。

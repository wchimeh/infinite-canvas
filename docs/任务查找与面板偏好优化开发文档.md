## 开发文档：任务查找与面板偏好优化

### 背景
底部面板刷新后丢失折叠状态，任务累积后仅靠队列和状态难以快速找到目标。

### 目标
- [x] 在当前浏览器记住底部面板展开偏好。
- [x] 支持搜索任务并一键清除组合筛选。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/Timeline.tsx` | 修改 | 读取和保存折叠偏好，容错浏览器存储失败 |
| `apps/desktop/src/TaskCenter.tsx` | 修改 | 搜索节点名称、任务 ID 和任务信息，清除筛选 |
| `apps/desktop/src/workbench.css` | 修改 | 搜索栏宽窄屏布局 |
| `scripts/result-actions-smoke.mjs` | 修改 | 回归搜索和折叠持久化 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：Timeline 加载本地偏好；输入存储值，输出初始折叠状态；操作后保存，读取或写入失败不影响面板，提交任务仍自动展开。
- [x] 任务 2：TaskCenter 添加搜索；输入名称、节点 ID、任务 ID 或任务信息关键字，输出与队列和状态共同过滤的列表；忽略首尾空白与英文大小写，清除筛选恢复全部任务。
- [x] 任务 3：workbench.css 设置搜索布局；输入桌面或窄屏宽度，输出可换行、无横向溢出的输入框和清除按钮。
- [x] 任务 4：扩展浏览器脚本；输入模拟任务，验证搜索命中、不命中、清除恢复、折叠刷新保留、提交自动展开和原有复制定位功能；所有写请求拦截。
- [x] 任务 5：执行构建及多尺寸浏览器验证，记录结果。
- [x] 任务 5a：修正截图发现的搜索标签折行；输入横向搜索行，输出标签不换行且输入框可收缩，重新构建并检查多尺寸。

### 验收标准
- [x] 刷新页面保留底部折叠状态，存储不可用时功能仍可操作。
- [x] 搜索与已有筛选组合生效，空结果可直接清除筛选。
- [x] 类型检查、构建及浏览器测试通过，不产生真实生成调用。

### 风险点
- 浏览器本地存储可能不可用，必须捕获异常，不影响业务操作。
- 搜索只在当前项目已加载的任务中进行，不跨项目搜索。
- 偏好保存在当前浏览器，不修改项目文档或云端配置。

- `pnpm build` 通过，包含 TypeScript 检查；仍有现有主包超过 500 kB 的提示。
- `node scripts/result-actions-smoke.mjs` 通过：名称、任务 ID、任务信息搜索，大小写及空白处理，无匹配项、组合筛选和清除恢复；折叠刷新保留、存储访问失败容错、提交自动展开；复制和定位回归通过。写请求全部模拟，无真实生成调用。
- `node scripts/ui-polish-smoke.mjs` 通过：1440、1024、390 宽度检查。桌面截图发现搜索标签换行，修正后重新构建与验证通过。
- 正常工作台保持运行，刷新即可加载本次修改。

### 验收标准
- [x] 不是仅增加连接点：请求中存在真实音频、视频内容。
- [x] 图片既有行为、时间继承和文本输出不变，顺序稳定。
- [x] 错误媒体、过量媒体与不兼容模型明确报错，不丢弃参考后静默生成。
- [x] 页面显示下一连接点，选择配置可持久化。

### 风险点
- 采用兼容 Chat Completions 的 input_audio / video_url 扩展；模型与网关必须支持。仅支持文本或图片的模型无法理解音视频。
- 每段原始媒体限制 20 MiB/120 秒，超限提示先用裁剪节点；视频转为最长边不超过 720 的 H.264/AAC MP4，音频转为 16kHz 单声道 WAV，输出单段不超过 20 MiB。
- 使用 FFmpeg；不同服务商还可能有更严格的数量或大小限制。
- 不调用付费接口验证，不自动重新打包 EXE。

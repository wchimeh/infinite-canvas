## 开发文档：视频输入候选封面

### 背景
输入候选浮层的视频目前只显示图标，缺少用于辨认内容的封面缩略图。

### 目标
- [x] 已有视频素材在输入候选列表显示首帧封面。
- [x] 提取失败时回退图标，不影响选择连线及原视频文件。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_thumbnails.py` | 修改 | 视频封面、缓存和失败测试 |
| `services/backend/app/video_thumbnail.py` | 新建 | 限时提取和有界内存缓存 |
| `services/backend/app/main.py` | 修改 | 缩略图接口支持视频 |
| `scripts/input-port-picker-browser.mjs` | 修改 | 导入真实视频并验证封面及失败回退 |
| `apps/desktop/src/InputPortPicker.tsx` | 修改 | 视频候选渲染缩略图 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：定位原因；输入前端候选渲染及缩略图接口代码，输出图片专用分支导致视频无封面的结论。
- [x] 任务 2：添加后端测试；输入真实横竖视频、损坏媒体及不支持的音频，输出首帧、尺寸、缓存、原文件不变及失败响应断言。
- [x] 任务 3：实现视频缩略图工具；输入本地视频路径，输出最长边不超过 480px 的 JPEG，使用 15 秒超时及最多 128 项缓存。
- [x] 任务 4：扩展缩略图接口；输入视频素材 ID，输出 JPEG 与私有缓存头，运行后端测试验证。
- [x] 任务 5：扩展浏览器验收；输入真实视频素材，输出视频候选图像加载、连线、封面请求失败回退断言；先验证旧前端不能通过。
- [x] 任务 6：修复候选预览组件；输入有素材的视频候选，输出与图片一样的封面，保留无素材和加载失败图标。
- [x] 任务 7：构建、回归并复核截图；输入完整修改，输出测试结果及最终截图记录。

### 验收标准
- [x] 视频候选显示真实首帧，保持比例且最大边不超过 480px。
- [x] 图片预览、音频图标、搜索和自动连线不受影响。
- [x] 无视频结果、损坏文件、缺少 FFmpeg 或封面请求失败时可正常回退。
- [x] 缩略图不修改视频源文件，重复请求复用缓存。

### 风险点
- 视频解码依赖项目已有 FFmpeg，子进程需隐藏窗口并设置超时。
- 缓存按文件路径、大小和修改时间区分，设置条目上限，避免无限增长。
- 仅修复本次候选浮层封面，不修改日常项目或触发云端生成。

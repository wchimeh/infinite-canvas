## 开发文档：原分辨率成片预览

### 背景
成片预览仍将长边缩小到约 720 像素，用户要求按原视频分辨率预览。

### 目标
- [x] 原片模式按原素材尺寸预览，时间线合成模式按所选画幅预览。
- [x] 不复用旧低分辨率缓存，界面明确预览与无损导出的区别。

| 文件路径 | 操作类型 | 说明 |

### 验收标准
- [x] 横竖屏及小尺寸预览均不因预览模式改变尺寸。
- [x] 时间线合成预览与正式导出的布局一致。
- [x] 旧预览缓存失效，新缓存仍复用。
- [x] 正式导出的逐帧无损回归通过，前端构建通过。

### 风险点
- 原分辨率预览的耗时和文件大小增加。
- 预览采用浏览器兼容的高质量有损编码；正式导出仍无损。原分辨率不等于编码无损。
- 不自动修改已有项目数据；需重新点击合成预览。本次不重新打包 EXE。

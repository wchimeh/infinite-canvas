## 开发文档：提取分镜时长约束

### 背景
每条提取分镜应适合一次视频生成，将时长统一约束为 4–15 秒。

### 目标
- [x] 模型按每条 4–15 秒规划动作和对白。
- [x] 后端拒绝不符合时长要求的分镜，避免流入视频节点。

| `services/backend/app/providers.py` | 修改 | 提取分镜提示词、时长校验和缓存版本 |

- [x] 任务 2：修改分镜生成规则；输入故事和模型 JSON，输出每条 durationMs 为 4000–15000 的整数，非法值报错；更新文本适配版本使新任务不复用旧规则缓存；新增 13 项测试通过。

### 验收标准
- [x] 请求明确每条分镜 4–15 秒，并要求动作对白可在该时长内完成。
- [x] 4000 和 15000 毫秒均接受；越界、缺失和非整数时长均拒绝。
- [x] 后端回归通过。

### 风险点
模型输出不合规会使本次提取失败，需要重新运行；已有分镜不自动修改。仅调整提取分镜规则，视频工作流自身的时长范围继续由对应工作流决定。

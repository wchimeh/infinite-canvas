## 开发文档：扩写节点多参考图

### 背景
文本服务已经支持多图，但扩写画布仅一个图片连接点，需要与视频节点的多参考图对齐。

### 目标
- [x] 支持9个自动展开的参考图片连接点。
- [x] 按连接点编号向模型传图，保持与视频引用顺序一致。

### 验收标准
- [x] 九图按编号传递、超限拒绝。

### 风险点
模型必须支持图像输入，图片编号应与视频节点相同；连线加勾选总数受9张限制。现有项目不自动补连线。

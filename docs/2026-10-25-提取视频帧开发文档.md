### 验收标准
- [x] 可从节点列表添加并连接视频，输出图片可连接后续图片输入。
- [x] 拖动进度条后输出所选时间正在显示的帧，不误取后一帧。
- [x] PNG 保持源画面分辨率，无云端费用，源文件不变。
- [x] 缺少视频、时间越界、预览错误均明确提示；保存后保留时间选择。

### 风险点
浏览器不支持的源编码可能无法预览，但仍可填写时间在本地处理。精确定位按视频帧时间戳选择当前帧，长视频需额外解码扫描，使用现有媒体处理超时保护。不同解码器对 HDR 色彩呈现可能不同，PNG 不承诺保留 HDR 元数据。已采用输出沿用现有锁定规则，重新截取可更新候选结果。

### 验收标准
- [x] 连续断网超过四次、跨两小时及应用恢复后仍保留原任务 ID。
- [x] 下载断网自动续查/重新下载，不重复提交生成任务。
- [x] 正常查询恢复后清除错误；云端明确失败和鉴权失败不无限重试。
- [x] 没有云端 ID 的不确定提交不自动重提；等待时仍可取消。

### 风险点
- 已提交的任务仍占用媒体并发额度，避免本地断网期间超量提交。
- 云端明确返回仍在排队/运行时保留两小时保护；重连成功后重新计算等待窗口。
- 恢复下载采用重新下载文件，不实现 HTTP 字节断点续传。
- 不调用收费接口，使用确定性的网络异常模拟验收。

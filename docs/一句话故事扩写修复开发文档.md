## 开发文档：一句话故事扩写修复

### 背景
用户输入一句话故事并连接扩写节点后，模型返回要求补充原始故事，而没有生成剧本。

### 目标
- [x] 验证上游文字进入真实文本适配器的 HTTP 请求体。
- [x] 扩写支持一句话创意，真正空白输入在请求前拒绝。
- [x] 新指令不复用旧指令生成的缓存。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_text_input.py` | 新建 | 上游文本 HTTP 载荷、空输入与版本回归 |
| `services/backend/app/providers.py` | 修改 | 一句话创意扩写指令、空白保护、版本号 |
| `services/backend/app/worker.py` | 修改 | 文本任务快照使用文本适配器版本 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：编写测试并验证当前行为；输入故事节点和扩写连线，断言最终 HTTP user 内容包含上游原文及本节点补充；新增一句话指令、空输入及版本预期。
- [x] 任务 2：修改 TextProvider；输入简短创意，指令明确直接创作、合理补全、不追问；空白输入报可操作错误；升级版本。
- [x] 任务 3：修改 worker 文本版本快照；文本生成采用 TextProvider.version，使新指令缓存键变化；空文本在费用预留和 submitted 标记之前拒绝，其他生成队列不改变。
- [x] 任务 4：执行后端回归，重启正常服务加载修改，并对用户扩写节点强制执行一次真实验证，检查返回正文。

### 验收标准
- [x] 上游故事及补充提示完整进入 HTTP 请求。
- [x] 一句话创意生成实际剧本，空白文本不发出 HTTP 请求。
- [x] 旧缓存不被新指令命中，后端回归通过。
- [x] 正常实例恢复，记录真实生成验证结果。

### 风险点
- 模型输出有随机性，指令不能代替真实调用验证。
- 验证会对当前扩写节点生成一个新的任务结果，保留历史任务，不运行图视频节点。
- 重启前确认没有正在运行的生成任务。

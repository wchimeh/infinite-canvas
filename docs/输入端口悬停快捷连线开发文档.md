## 开发文档：输入端口悬停快捷连线

### 背景
通过输入端口直接选择画布上的兼容输出，减少寻找节点并手动拖线的操作。

### 目标
- [x] 悬停节点输入点，显示整个画布中可连接的同类型输入来源。
- [x] 点击候选自动连线，并保留现有替换、撤销、类型及循环依赖校验。

### 验收标准
- [x] 悬停参考图输入点时展示整个画布的兼容图片来源，已有可用图片显示缩略图。
- [x] 文本、音频和视频端口按对应类型筛选，不能选择自身或会形成循环的节点。
- [x] 鼠标从输入点进入浮层不会使其提前关闭，列表支持滚动与名称搜索。
- [x] 已连接项标记状态且不重复连接；选择其他项替换该输入点的原连线，支持撤销。
- [x] 无候选、预览缺失及连接失败均有明确反馈。
- [x] 原手动拖线、动态参考图端口与画布缩放平移可正常使用。

### 风险点
- 工作区已有大量未提交改动，实现需保留原有内容，仅增量修改本功能相关部分。
- 端口跟随画布缩放，浮层应使用屏幕坐标定位，避免缩放过小或被节点裁切。
- 悬停打开需要短延迟，离开需要过渡时间；开始拖线时应关闭浮层，避免遮挡。
- 候选展示期间画布可能发生变化，点击时仍须调用现有 connect 方法重新校验。

### 交互设计（已确认）
- 推荐端口旁轻量浮层；侧栏选择需要更远的鼠标移动，居中弹窗会打断画布操作，因此本次不采用。
- 悬停约 250ms 打开，移出端口与浮层约 200ms 后关闭；Esc、点击外部或开始拖线关闭。
- 浮层显示输入类型、搜索框和候选列表。图片显示缩略图及节点名称，文本显示摘要，音视频显示对应类型图标及名称。
- 候选范围为整个当前画布的兼容输出，包括屏幕外节点；素材库中未加入画布的素材不列入。
- 尚未生成的兼容输出节点也可用于建立依赖，显示“尚无预览”；不把失效的旧结果当作当前可用图片展示。
- 已占用输入点选择其他来源时，沿用现有规则替换该端口的连线；不影响其他输入点。
- 点击成功后关闭浮层，现有状态管理负责撤销记录、下游失效和时长同步；失败在浮层显示原因。

## 开发文档：任务信息状态修复

### 背景
任务中心只依据云端任务 ID 显示说明，导致已完成任务仍显示等待本地调度。

### 目标
- [x] 任务信息与实际状态一致。
- [x] 已完成任务说明结果类型或缓存复用，并提示查看结果。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/taskInformation.ts` | 新建 | 按状态生成说明 |
| `apps/desktop/src/Timeline.tsx` | 修改 | 任务中心采用状态说明 |
| `scripts/test-task-information.mjs` | 新建 | 状态组合回归 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：实现说明函数；输入任务状态、输出、错误及云端 ID，输出与状态一致的中文说明。
- [x] 任务 2：替换任务中心文案；输入任务列表，输出正确说明，不改变调度和重试行为。
- [x] 任务 3：添加状态回归检查；输入完成、排队、运行、失败、取消及缓存任务，验证说明不混淆。
- [x] 任务 4：运行回归、类型检查和构建，并确认现有开发实例可用；输出检查结果。

### 验收标准
- [x] 已完成任务不再显示等待本地调度。
- [x] 仅未取得云端 ID 的排队任务显示等待本地调度。
- [x] 原错误信息仍优先显示，状态相关操作不变。

### 风险点
- 没有云端 ID 不代表本地生成，文本接口也可能没有 ID；运行时使用中性文案。
- 已完成不代表用户已批准结果，提示仅引导查看。

### 验证结果
- 状态组合回归通过，TypeScript 检查和生产构建通过。
- 只读打开现有开发实例任务中心，4 条已完成任务均未显示等待本地调度。
- 未提交生成任务，现有本地服务继续运行。

## 开发文档：文本结果编辑

### 背景
生成文本需要人工修改，并将修改稿实际用于后续生成。

### 目标
- [x] 生成文本可以编辑、保存、取消和恢复原始结果。
- [x] 修改稿随项目保存，下游使用修改稿，结构化数据保持一致。

### 验收标准
- [x] 剧本、扩写、角色/场景/分镜提取和文本拼接结果可编辑；结构化结果以 JSON 编辑并校验。
- [x] 保存修改稿后不调用模型，上游不重跑，下游接收新内容；重新打开项目后保留。
- [x] 保留原任务结果；恢复生成结果可解除修改稿并重新生成。修改稿启用期间运行该节点采用修改稿。
- [x] 视频扩写保留参考图顺序及原时长，校验格式和对白时长；编辑不能绕过安全约束。
- [x] 验证、打包及安装测试通过。

### 风险点
- 修改稿是明确采用的输出，需恢复原始结果才能重新生成；界面必须解释该行为。
- 异步保存期间切换项目或节点时不得把结果写到新项目。
- 已经排队的任务使用原快照，需要新运行才能采用修改稿。
- 结构化编辑需保留字段格式；不支持直接修改分镜选择节点，应修改源分镜列表后重新选择。

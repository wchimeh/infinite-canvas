## 开发文档：扩写视频参考一致性

### 背景
扩写和视频使用独立图片输入，目前没有检查相同图片编号是否指向同一素材。

### 目标
- [x] 新扩写记录参与分析的图片内容及顺序。
- [x] 视频提交前拒绝已知的图片缺失、增减、换图和顺序错位。

### 任务清单（必须全部标记完成）
- [x] 任务 1：有图片的扩写输出 referenceImageHashes，按原始图片字节计算 SHA256；无图扩写保留原返回结构。
- [x] 任务 2：视频输入收集后比对上游扩写哈希，拒绝不一致，明确补齐并同序连接提示；不阻止已提交云端任务结果轮询；更新扩写版本使新运行记录哈希。
- [x] 任务 3：验证哈希顺序、匹配通过及增减错序拒绝，完成后端回归。

### 验收标准
- [x] 有图扩写与视频的内容/顺序可核对，不自动调换图片或静默忽略。
- [x] 无图扩写和无此元数据的历史任务保持兼容。

### 风险点
按文件字节比较，同一图重新编码可能触发不一致，应复用素材库中的同一文件。只能确保输入一致，不能保证模型身份保持或物理动作正确。历史缺少哈希的任务需重新扩写才能启用校验。

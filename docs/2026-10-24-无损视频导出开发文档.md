## 开发文档：无损视频导出

### 背景
用户要求不能损失原画质，上一版 CRF 16 仍然有损，需要使用真正无损编码和逐帧像素验证。

### 目标
- [x] 正式 MP4 使用无损视频编码，预览保持轻量。
- [x] 同尺寸同帧率的普通剪辑输出像素与原片完全一致。
- [x] 明确缩放、帧率及像素格式转换的边界，不能将无损编码等同于任意合成完全保留源像素。

### 验收标准
- [x] 同尺寸同帧率、无特效的 YUV420P 片段输出与源视频解码像素完全相等。
- [x] 预览仍可低分辨率运行，正式编码不降级到有损参数。
- [x] 对画幅缩放与源像素格式的限制如实说明并完成相关处理。

### 风险点
- 无损 MP4 会明显增大；部分播放器或浏览器不支持 H.264 无损配置，需要用支持的桌面播放器播放。
- 无损编码只能保证编码输入不受量化损失，缩小、裁切、降帧率、色度/位深转换仍可能丢失源信息。
- 本任务限定画质，音频混音保持现有逻辑，不将 AAC 音频宣传为无损。
- 默认原片模式只处理普通顺序剪辑，拒绝重叠、字幕、透明与淡入淡出，避免悄悄改变像素；这些编辑可显式选择时间线合成模式。
- 首版严格原片模式支持 SDR、有限范围 YUV420P、相同整数帧率 1–120 fps；其他格式或不同帧率明确拒绝，绝不静默降级。以后可扩展无损像素格式处理。
- 原片模式会忽略旧的全画幅适配尺寸，但不会忽略显式叠加和变换；原始项目文档不改变，实际渲染参数写入 manifest。

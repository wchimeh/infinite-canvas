## 开发文档：文本思考与流式接收

### 背景
Qwen扩写在120秒非流式等待后失败且显示笼统错误，需要可控思考模式及流式传输。

### 目标
- [x] 每个自定义文本服务可设置默认/开启/关闭思考及流式接收。
- [x] 区分连接超时、流等待超时和中途截断，不采用不完整结果或自动重复收费。

### 验收标准
- [x] 思考模式关闭时实际请求含enable_thinking=false，默认时不发送扩展参数。
- [x] 流式正文正确拼接，思考片段不混入结果，流中断不缓存部分结果。
- [x] 超时信息明确且不自动重复生成，测试与构建通过。

### 风险点
enable_thinking为兼容服务扩展参数，不支持的服务应选择默认；流式只改变接收方式，界面仍在完整格式校验后展示结果。超时后服务商仍可能计费。不重启有活动任务的服务。

## 开发文档：一键连接上游参考图

### 背景
后续节点需要一键复用上游参考图，并自动显示连接线。

### 目标
- [x] 点击按钮后自动连接上游使用的参考图片节点。
- [x] 素材勾选参考图自动创建或复用图片素材节点，保持图片顺序。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/upstreamReferences.ts` | 新建 | 生成节点及连线方案 |
| `apps/desktop/src/store.ts` | 修改 | 一次应用并支持撤销、下游标记更新 |
| `apps/desktop/src/Inspector.tsx` | 修改 | 一键按钮及结果提示 |
| `apps/desktop/src/upstreamReferences.test.mjs` | 新建 | 顺序、复用、上限、保留音视频验证 |
| `package.json` | 修改 | 注册回归测试 |
| `scripts/upstream-references-browser.mjs` | 新建 | 真实按钮操作及保存重开验收 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：实现连线方案；输入当前节点、直接上游、素材及图结构，输出新的图片连线、必要素材节点、配置；按上游图片端口编号再勾选顺序连接。
- [x] 任务 2：添加 store 操作；输入当前节点 ID，一次应用方案并记录单次撤销，标记下游需更新。
- [x] 任务 3：加入“连接上游参考图”按钮；输入用户点击，输出明确成功数量或失败原因，运行期间禁用。
- [x] 任务 4：添加纯函数回归并加入 verify，验证多图顺序、素材节点复用、保留音视频、缺失和超限时不部分修改。
- [x] 任务 5：浏览器验证点击即连线、自动显示下一个端口、撤销及保存重开；运行构建和测试。

### 验收标准
- [x] 优先使用直接文本上游的参考图；无文本上游时使用唯一图片上游；多个候选时提示，不任意选择。
- [x] 已有图片连线的源节点直接复用；勾选素材通过图片素材节点接入。
- [x] 替换当前图片参考，保留文本、音频、视频输入；顺序与上游一致，不额外重复勾选。
- [x] 无参考、素材缺失、超出当前图片输入口数量时明确提示，原画布不变。
- [x] 一次撤销恢复原图，保存重开仍保持新连线。

### 风险点
- 有多个参考图但目标只有一个图片输入口时提示端口不足，不擅自扩展节点契约。
- 新建素材节点需避开已有节点；生成节点本身无需已完成即可复用其输出连线。
- 上游之后修改参考图时需再次点击同步；复制不改动上游。
- 不调用云端、不重新打包 EXE。

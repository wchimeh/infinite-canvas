## 开发文档：生成失败恢复与凭据操作修复

### 背景
检查发现文本服务明确拒绝请求时被误判为提交不确定，默认工作流参数错误可能留下费用预留，撤销凭据会被无关草稿阻止。

### 目标
- [x] 文本服务明确拒绝的请求提供准确错误，允许直接重试并释放本次费用预留。
- [x] 默认及自定义云端工作流在提交与费用预留前验证参数。
- [x] 撤销已有文本服务密钥不依赖其他设置草稿是否合法。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_generation_profiles.py` | 修改 | 文本响应分类、费用记录及默认工作流参数回归 |
| `services/backend/app/providers.py` | 修改 | 文本 HTTP 状态分类 |
| `services/backend/app/worker.py` | 修改 | 限流拒绝释放预留、默认工作流预检 |
| `scripts/smoke.mjs` | 修改 | 未完成草稿期间撤销凭据的模拟交互 |
| `apps/desktop/src/GenerationProfiles.tsx` | 修改 | 撤销凭据不触发保存配置 |
| `README.md` | 修改 | 失败恢复说明 |

### 验收标准
- [x] 密钥无效、参数拒绝、模型不存在、限流错误不误报提交不确定。
- [x] 明确拒绝不会保留本次费用预留，用户可以手动重试，不自动发起新的收费请求。
- [x] 服务器错误、网络中断或返回格式错误仍提示核查账单。
- [x] 默认工作流非法输入在提交之前终止，已提交远端任务的查询不受影响。
- [x] 撤销凭据不保存或丢弃未完成草稿。
- [x] 全套回归通过，不调用真实收费服务。

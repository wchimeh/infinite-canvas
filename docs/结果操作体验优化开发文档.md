## 开发文档：结果操作体验优化

### 背景
白色主题已完成，任务中心选择离屏节点后仍不可见，文本结果缺少直接复制入口。

### 目标
- [x] 任务中心选择节点后，画布定位到该节点。
- [x] 复制本次任务文本，并提供成功和失败反馈。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/store.ts` | 修改 | 临时定位请求，加载项目时清空 |
| `apps/desktop/src/Canvas.tsx` | 修改 | 消费请求并居中显示节点 |
| `apps/desktop/src/TaskCenter.tsx` | 修改 | 发起定位、复制文本及反馈 |
| `apps/desktop/src/workbench.css` | 修改 | 结果标题与操作的响应式布局 |
| `apps/desktop/src/Timeline.tsx` | 修改 | 底部面板收起和展开 |
| `scripts/result-actions-smoke.mjs` | 新建 | 浏览器验证复制与离屏定位 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：store 增加 focusRequest；输入节点 ID，输出一次性请求；项目加载清空，不写入画布文档。
- [x] 任务 2：Canvas 消费请求；输入存在的节点，输出居中的节点与可见画布；缺失节点安全忽略，减少动态效果偏好下不动画。
- [x] 任务 3：TaskCenter 选择操作发起定位；文本结果提供复制按钮，输入当前任务正文，输出剪贴板内容和反馈；切换结果清空反馈，异步返回不污染新结果。
- [x] 任务 4：workbench.css 添加文本结果操作布局；输入桌面或窄屏尺寸，输出不溢出的操作行。
- [x] 任务 4a：Timeline 增加底部收起按钮；输入用户切换动作，输出仅保留页签的面板；页签点击及新任务提交自动展开，保留当前筛选与时间线状态。
- [x] 任务 4b：workbench.css 添加折叠高度规则；输入折叠状态，输出桌面画布扩展及窄屏无空白占位。
- [x] 任务 5：添加并运行浏览器验证；通过只读接口响应模拟离屏节点、历史文本，验证定位、重复定位、复制成功/失败和关闭重开；拦截写请求，避免修改正常项目。
- [x] 任务 6：运行类型检查、构建及多尺寸检查，记录结果，确认正常实例可用。

### 验收标准
- [x] 离屏节点可定位，重复点击仍有效，节点配置不改变。
- [x] 剪贴板与当前任务正文完全一致，拒绝权限时显示可操作提示。
- [x] 弹窗重开不残留复制反馈，窄屏操作无溢出。
- [x] 时间线与任务中心均可收起，点击页签和提交任务可展开。
- [x] 类型检查、构建和浏览器检查通过，未调用生成接口。

### 风险点
- 剪贴板可能被浏览器权限阻止，捕获异常并提示手动选择正文。
- 画布采用可见节点渲染，离屏节点尺寸可能未测量，使用节点默认尺寸定位。
- 定位请求仅用于交互，不应进入保存或撤销历史。

## 开发文档：项目数据默认保存目录

### 背景
允许在设置中指定整个项目数据的默认目录，避免数据固定占用系统盘。

### 目标
- [x] 设置中展示当前目录并支持保存下次启动使用的绝对路径。
- [x] 重启后实际读取新目录，保留原目录数据和服务配置。
- [x] 清楚显示待重启状态，支持撤销待生效更改。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/app/project_storage.py` | 新建 | 目录配置、可写校验、启动解析 |
| `services/backend/app/main.py` | 修改 | 设置 API 与默认启动目录 |
| `scripts/backend_entry.py` | 修改 | EXE 启动读取目录配置 |
| `apps/desktop/src/StorageSettings.tsx` | 新建 | 数据目录设置面板 |

### 验收标准
- [x] 目录更改不是仅改变页面文字；下次启动实际使用配置目录。
- [x] 非绝对路径、文件路径、不可写路径明确拒绝，不覆盖旧配置。
- [x] 原项目文件、模型配置和密钥不被清理。
- [x] 当前使用位置与重启后的保存位置清晰可见。

### 风险点
- 本次仅切换目录，旧项目不自动迁移；页面明确提示空目录不会显示原项目。
- 服务设置和凭据保留固定位置；项目数据位置单独持久化。
- 不可访问的新目录需在启动时回退并显示原因，避免应用无法打开。

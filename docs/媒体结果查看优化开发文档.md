## 开发文档：媒体结果查看优化

### 背景
任务结果中的媒体加载失败时缺少可操作提示，也没有统一的原文件下载入口。

### 目标
- [x] 图片、视频和音频预览失败时明确提示并支持重新加载。
- [x] 存在的素材支持下载原文件，缺失素材不显示无效操作。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/MediaResult.tsx` | 新建 | 单个任务媒体结果的预览、错误恢复和下载 |
| `apps/desktop/src/TaskCenter.tsx` | 修改 | 接入媒体结果组件 |
| `apps/desktop/src/workbench.css` | 修改 | 媒体标题与操作的响应式样式 |
| `scripts/media-results-smoke.mjs` | 新建 | 模拟素材响应验证失败恢复和下载 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：创建 MediaResult；输入素材记录或缺失状态，输出预览与下载链接；图片 load、视频/音频 loadedmetadata 清除加载提示，error 显示重试，重试只重新 GET 素材，缺失素材显示提示。
- [x] 任务 2：TaskCenter 接入；输入本次任务素材 ID，输出逐项媒体组件；切换任务时重建状态，不影响历史输出和已采用版本。
- [x] 任务 3：workbench.css 添加标题、操作和状态样式；输入长文件名和小屏，输出不溢出的布局。
- [x] 任务 4：添加浏览器测试；模拟图片先失败后成功、视频/音频失败、缺失素材及未知格式，验证重试、下载文件内容、窄屏和弹窗重开；禁止真实写请求和生成调用。
- [x] 任务 5：构建、执行新增及已有结果操作回归和多尺寸检查，记录结果。

### 验收标准
- [x] 媒体失败后有明确提示，可重试而不触发生成。
- [x] 下载保持原始文件内容，缺失素材不显示下载入口。
- [x] 切换任务或重开弹窗时状态正确，键盘可操作。
- [x] 类型检查、构建与浏览器验证通过。

### 风险点
- 浏览器可能不支持某些编码，提示用户下载原文件使用本地播放器查看。
- 下载沿用同源认证接口与浏览器下载能力，不把大文件整体读入前端内存。
- 未知格式只提供下载，不尝试嵌入执行。

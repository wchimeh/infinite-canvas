## 开发文档：场景提取与四视图生成

### 背景
用户要求新增场景提取与场景生成节点，场景图片为四视图；同时完成进行中的角色三视图。

### 目标
- [x] 剧本提取场景资料，确认后入场景库并创建独立生成节点。
- [x] 同一场景一张 2×2 四视图，分别为前、右、后、左视角。

### 风险点
- 四视图采用前、右、后、左四个方向的约定，不保证模型严格遵循几何关系，需人工审核。
- 自定义工作流尺寸由模板决定，建议使用方形画布容纳四宫格。
- 场景是可复用环境参考资产，区别于剧集中的剧情场次；不自动覆盖既有场景资料。

### 验收标准
- [x] 图片视频统计共用额度，LLM 单独展示，跨项目合计。
- [x] 远端排队、运行中和正在取消占用额度；本地待提交计入待调度。

### 风险点
- 统计是刷新时刻的快照，调度变化最多延迟约两秒显示。
- 待调度包含等待上游及等待重试时间的任务，不等于立即可运行。

## 开发文档：连线操作区域优化

### 背景
节点连接点只有 8 像素，连线和选线时难以准确命中。

### 目标
- [x] 扩大连接点的可见尺寸和鼠标操作范围。
- [x] 提高连线吸附和选中连线的容错，保持多参考图端口清晰。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/workbench.css` | 修改 | 圆点尺寸、命中区域、端口间距、交互反馈 |
| `apps/desktop/src/Canvas.tsx` | 修改 | 吸附距离和连线点击区域 |
| `scripts/connection-hit-area-browser.mjs` | 新建 | 偏移拖动、连线选择和动态端口浏览器验收 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：修改样式；输入鼠标悬停/连接状态，输出 14px 圆点、28px 命中区域和明显反馈；端口行距 32px，避免相邻命中区域重叠。
- [x] 任务 2：修改画布配置；输入靠近端口或连线的鼠标操作，输出 32px 吸附范围、32px 连线点击区域。
- [x] 任务 3：增加真实浏览器回归；验证从圆点外侧启动拖动、目标附近释放可连接、偏离线条可选中，以及多参考图动态端口。
- [x] 任务 4：类型/构建、浏览器测试及截图检查通过，记录结果。
- [x] 任务 4a：修正截图发现的旧主题选线颜色覆盖，明确选中连线变量并增加颜色断言。

### 验收标准
- [x] 可从圆点外的透明操作范围开始连线，并吸附到目标端口。
- [x] 连线可在较宽范围内选中，选中颜色和粗细明显。
- [x] 动态参考图端口依然自动增加，各端口互不遮挡。
- [x] 保留白色界面和现有素材类型颜色，不改变连接替换规则。

### 风险点
- 极小缩放下画布元素仍随缩放变小，实际验收覆盖常用缩放。
- 只扩大操作范围，不改变输入输出类型校验和生成逻辑。
- 更新前端构建，暂不覆盖旧安装包。

### 验证结果
- TypeScript 与前端构建通过。
- 真实浏览器在 100% 和缩小后验证：圆点外起拖、目标附近吸附、宽范围选线及动态端口通过。
- 选中连线颜色/粗细断言通过，截图已复核；多节点拖动回归通过。

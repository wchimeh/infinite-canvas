## 开发文档：视频参考自动扩展

### 背景
生成视频需要最多 9 张图片、3 段音频、3 段视频，并在连线后自动出现下一个连接点。

### 目标
- [x] 三类参考端口自动扩展，不再显示手动添加按钮。
- [x] 工作流映射和实际输入支持图片 9、音频 3、视频 3 的上限。

### 任务清单（必须全部标记完成）
- [x] 任务 1：graph 定义 image 至 image9、audio 至 audio3、video 至 video3，旧端口 ID 兼容。
- [x] 任务 2：视频工作流媒体映射接受图片索引 0–8，音频/视频索引 0–2，超限拒绝；其他节点保持原限制。
- [x] 任务 3：worker 对三类编号端口排序并归一媒体类型，连线与勾选合计超出 9/3/3 时提交云端前报错。
- [x] 任务 4：Canvas 每类显示已连接最大编号再加一个空端口、达到上限停止；移除添加按钮；Inspector 说明自动扩展和上限。
- [x] 任务 4b：工作流编辑器根据所选适用节点与媒体类型设置素材序号上限，支持第 9 张图和第 3 段音频/视频。
- [x] 任务 5：后端和浏览器验证自动展开、媒体上限、索引范围和顺序；完整构建回归。
- [x] 任务 6：队列空闲后重启验证服务并记录结果。

### 验收标准
- [x] 首次显示参考图 1、参考音频 1、参考视频 1，连线后自动出现各自下一端口。
- [x] 9/3/3 上限同时适用于实际传入媒体，工作流索引正确。
- [x] 删除连线不隐藏仍有连接的更高编号端口，旧连线不丢失。

### 风险点
没有连线的中间端口跳过，输入按编号压紧；勾选素材按类型追加在连线素材之后。实际工作流仍需配置相应映射。

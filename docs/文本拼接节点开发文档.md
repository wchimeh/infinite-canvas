## 开发文档：字符串文本拼接节点

### 背景
需要把多个故事或模型输出按指定顺序组合成下游可用的文本。

### 目标
- [x] 添加本地文本拼接节点，不调用云端且不产生生成费用。
- [x] 支持10个编号文本输入，自动显示下一个连接点，按端口数字排序。
- [x] 支持换行、空格、无分隔符及自定义分隔符，保留输入空白和已连接的空字符串。

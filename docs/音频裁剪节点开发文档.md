### 验收标准
- [x] 输出内容为选择时间段，原素材不变。
- [x] 云端关闭仍可运行，不占用 LLM/媒体生成队列或收费额度。
- [x] 时间配置保存重开仍有效，结果可试听并连接下游音频输入。
- [x] 空结束时间取末尾，负数、非有限数字、倒置、越界及非音频输入明确失败。

### 风险点
- 使用内置 FFmpeg/FFprobe，本地开发需配置 FFMPEG_DIR。
- 时间以秒为单位，输出 WAV 体积可能大于压缩源文件。
- 不自动重新打包此前 EXE；本次交付源码和验证结果。

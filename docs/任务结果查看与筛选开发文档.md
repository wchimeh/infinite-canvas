## 开发文档：任务结果查看与筛选

### 背景
任务中心不能直接查看对应运行结果，回到节点可能误看最新任务且混合队列难以筛选。

### 目标
- [x] 按队列、状态筛选当前项目任务。
- [x] 每条任务直接预览该次运行的文本与媒体。
- [x] 可从任务选择对应画布节点，保留现有重试及取消操作。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/TaskCenter.tsx` | 新建 | 筛选、任务操作和对应结果预览 |
| `apps/desktop/src/Timeline.tsx` | 修改 | 嵌入独立任务中心 |
| `apps/desktop/src/style.css` | 修改 | 筛选及结果弹窗样式 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：实现任务中心组件；输入当前任务与素材，输出筛选列表、单次任务结果、选择节点和原操作；删除素材显示缺失提示。
- [x] 任务 2：时间线挂载任务中心；输入现有取消重试回调，输出行为兼容的任务页。
- [x] 任务 3：设置响应式样式；输入筛选器、文本和媒体，输出可滚动且窄屏不溢出的预览。
- [x] 任务 4：类型检查、构建及浏览器验证；覆盖筛选、打开与关闭真实已存文本结果及窄屏，不调用云端生成。

### 验收标准
- [x] LLM 与图片＋视频可单独筛选，待处理/完成/失败可筛选。
- [x] 历史任务预览只读取该 task.output，不使用节点最新任务结果。
- [x] 查看结果不触发生成、不修改采用版本或时间线。

### 风险点
- 已删除的素材不能预览，显示明确提示。
- 弹窗仅查看结果；采用版本仍在节点面板操作。

### 验证结果
- TypeScript 检查与生产构建通过。
- 浏览器验证真实已存文本、队列/状态筛选、历史结果隔离、Escape 关闭与 390px 弹窗布局通过。
- 历史任务测试仅拦截独立测试浏览器响应，未修改用户数据或调用生成。
- 本地服务继续运行，刷新即可加载新前端。

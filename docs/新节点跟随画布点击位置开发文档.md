## 开发文档：新节点跟随画布点击位置

### 背景
点击添加节点目前固定按网格放置，不能落在用户刚选择的画布位置。

### 目标
- [x] 未显式指定位置的新节点放在最近一次画布点击的坐标。
- [x] 缩放、平移正确换算，侧栏操作不改变位置，切换项目清空记录。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `apps/desktop/src/store.ts` | 修改 | 保存临时点击坐标并用作添加节点默认值 |
| `apps/desktop/src/Canvas.tsx` | 修改 | 捕获画布空白、节点及连线点击并换算坐标 |
| `scripts/node-placement-smoke.mjs` | 新建 | 浏览器验证坐标与显式定位优先级 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：store 增加临时坐标；输入显式位置/最近点击位置，输出节点左上角位置；优先显式坐标，未点击时沿用原网格默认值，load 时清空，不写入项目文件。
- [x] 任务 2：Canvas 使用已有 screenToFlowPosition 换算空白、节点、连线点击坐标；按钮、缩放控件和侧栏不覆盖记录。
- [x] 任务 3：浏览器模拟非默认缩放和平移，验证点击添加、缩放后保留画布点、拖入定位及重新加载后重置；所有业务写入模拟。
- [x] 任务 4：类型检查、生产构建和相关浏览器回归通过，刷新本地工作台。

### 验收标准
- [x] 新节点左上角对应最后一次画布点击位置。
- [x] 添加素材、角色参考等未传坐标的入口复用同一规则。
- [x] 拖入、右键派生节点、批量生成保留显式排列位置。
- [x] 记录位置不修改保存状态、不跨项目或刷新保留。

### 风险点
连续添加但未重新点击画布时，新节点会放在相同位置，符合最后点击位置规则；不自动偏移。记录的是画布坐标，后续平移缩放不会改变该画布位置。

- `node scripts/node-placement-smoke.mjs` 通过：非默认视口、空白/节点点击、缩放控件隔离、拖入优先、刷新重置及临时坐标不持久化。
- 角色批量生成、结果操作浏览器回归通过；`python scripts/check.py` 通过。
- 浏览器业务写入全部模拟，无真实项目修改和付费调用。前端静态资源已更新，本地工作台刷新后生效，无需重启后端。

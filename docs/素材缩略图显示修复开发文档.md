## 开发文档：素材缩略图方向与透明底色

### 背景
缩略图没有应用 EXIF 方向且透明通道被直接丢弃，可能与浏览器展示的原图不一致。

### 目标
- [x] 手机照片缩略图应用 EXIF 方向。
- [x] 透明图片缩略图使用白底，原始文件保持不变。

### 涉及文件
| 文件路径 | 操作类型 | 说明 |
|---------|---------|------|
| `services/backend/tests/test_thumbnails.py` | 新建 | 接口级方向、透明底和原图保留回归 |
| `services/backend/app/main.py` | 修改 | 修正缩略图转换顺序 |

### 任务清单（必须全部标记完成）
- [x] 任务 1：新增缩略图接口回归；输入带方向标签 JPEG、RGBA 和调色板透明 PNG、普通大图片，输出正确方向、白底、480像素上限和原图字节未变的断言；先复现失败。
- [x] 任务 2：修改缩略图接口；输入原始图片，先校正方向、缩放，再将透明图层合成到白底并输出 JPEG；任务1转绿。
- [x] 任务 3：运行完整验证并记录结果；输入最终代码，输出测试、类型检查和构建证据。

### 验收标准
- [x] EXIF 方向为6和8的缩略图方向正确。
- [x] RGBA及调色板透明区域为白色，主体颜色保留。
- [x] 输出尺寸不超过480像素，原始素材字节保持一致。
- [x] 全量验证通过，不调用云端、不修改用户项目数据。

### 风险点
JPEG为有损格式，颜色断言允许少量误差。仅修改缩略图显示，不转换存储原图、生成输入或导出素材。
